# Onchain Bunnies

A simple static coming-soon page for Onchain Bunnies.

## Preview locally

Open `index.html` directly in a browser, or run a local static server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This repository has no build step or dependencies. Point the hosting provider at the repository root and publish it as a static site.
